# Grid Overlay

Figma-style layout grid for the frontend of your WordPress site. Check alignment and spacing against your design, with separate settings for mobile, tablet, desktop and extended screens.

WordPress.org: https://wordpress.org/plugins/grid-overlay/

## Releasing

The plugin is published to WordPress.org from this repo.

- Push a tag like `1.1.1` (no `v`). The tag, the `Version` in `grid-overlay.php` and `Stable tag` in `readme.txt` must match.
- Banners, icons and screenshots live in `.wordpress-org/`. Pushing changes there to `main` updates the directory assets.
